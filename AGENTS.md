# Code review

When you have an open GitHub PR, and there are comments to your changes:

Make sure every comment is responded to: if you apply the suggested changes from the comment,
you can respond with just "Done.". 

If more discussion is needed, feel free to respond without making any changes, engaging in a back 
and forth with the reviewer.

Prefix all your code review comments with "Codex:" (or whatever your name is).

Do not resolve any of the comments, if you have not started the thread, only the author of the 
thread is allowed to resolve it.
